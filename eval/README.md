# Оценка на эталонном наборе

`pairs.csv` — 40 пар: 30 общеизвестных клинически значимых взаимодействий и 10 пар,
для которых взаимодействия не ожидается. Эталон составлен вручную (не из DailyMed /
PubMed), поэтому проверка не идёт по кругу. Набор маленький — это учебная оценка.

```bash
python -m eval.run_eval retrieval              # без LLM, бесплатно, ~12 мин
python -m eval.run_eval full --limit 10        # с LLM: 10 пар с взаимодействием + 10 без
```

Результаты: `results/retrieval.md`, `results/full.md` (и построчно `*.jsonl`).

## Итоги (ноябрь 2026)

**Поиск без LLM, 40 пар** (`results/retrieval.md`):
- чувствительность хотя бы по одному источнику — **30/30**; DailyMed 30/30, PubMed 29/30;
- в обеих инструкциях — 23/30; фрагмент из Boxed Warning / Contraindications — 11/30;
- только благодаря классам (RxClass) — 4/30;
- пары без взаимодействия: в 5/10 источники ничего не вернули, в 5/10 PubMed вернул статьи,
  где пару изучали (что с ними делать, решает агент — см. ниже).

Оценка нашла пропуск: **sildenafil + nitroglycerin** (DailyMed 0 фрагментов) — инструкции пишут
«organic nitrates» и «PDE-5 inhibitors», а классы RxClass называются «Nitrate Vasodilator» и
«Phosphodiesterase 5 Inhibitor». Добавлены сокращения в `CLASS_ALIASES`; DailyMed 29/30 → 30/30
(до исправления — `results/retrieval_before_aliases.md`).

**Полный конвейер с LLM, 20 пар** (`results/full.md`):
- пары с взаимодействием: ответ сообщает о взаимодействии — **10/10**;
- пары без взаимодействия: «не найдено» — 8/10. Скрипт отметил 2 оставшиеся как «найдено»,
  но вручную разобранные ответы **не заявляют значимого взаимодействия**:
  lisinopril + acetaminophen — «источники указывают на отсутствие клинически значимых
  взаимодействий, коррекция дозы не требуется»; acetaminophen + amoxicillin — «прямого
  клинически значимого взаимодействия не обнаружено», только данные на мышах.
  Итого ложных заявлений о взаимодействии — **0/10**. Метрика `found` в скрипте грубая:
  она считает «найдено» любой ответ, кроме стандартного «не найдено».
- замечаний критика на ответ: **1,0 → 0,2** после исправления; исправлено 8/8 ответов с
  замечаниями; без замечаний после исправления — 10/12;
- медиана 23 с на запрос; в среднем 3,2 вызова LLM; ~3,2 тыс. токенов gpt-oss + 1,8 тыс. qwen.

Сетевые сбои (DNS до dailymed.nlm.nih.gov) в полном прогоне затронули 2 пары: ответы
построены по оставшимся источникам, ошибка показана пользователю.
